### What I do

- ⚙️ **Laravel backends that carry the business logic** — multi-tenant ERPs with true data isolation, RBAC, queue-based orchestration on Horizon + Redis.
- 🖥️ **React / Next.js frontends that scale** — from admin dashboards to React Native mobile, sharing one typed API.
- 🤖 **AI agents through MCP** — autonomous workflows over OpenAI, Claude and Gemini using MCP servers and JSON-RPC, with LLM output reconciled back against the database.
- 🛰️ **Systems that talk to hardware** — a Galileosky TCP telemetry server with binary protocol parsing and CRC16 validation for unmanned fuel stations.
- 💳 **Payments done properly** — Stripe Connect, Paystack and Flutterwave with webhook verification and processor failover.

| --- | --- | --- |
